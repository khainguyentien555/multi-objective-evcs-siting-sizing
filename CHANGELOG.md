# Changelog

## 1.0.0 — 2026-09-24

Initial public archival release of the published-results reproducibility package for GTSD 2026 Paper ID 517.

### Included

- Frozen paper-facing Tables I, III, IV, V, and VI.
- Objective-weight robustness data reported in the paper text.
- Original result workbook from the GTSD working archive.
- Selected author-created figure sources.
- Python validation and figure-regeneration utilities.
- Source-workbook-to-publication lineage checks, including B&C half-up rounding.
- SHA-256 archival integrity manifest.
- Provenance, exclusions, and paper-to-data mapping documentation.

### Reproducibility boundary

The exact final camera-ready solver source was not present in the GTSD archive; this release therefore validates published numerical artifacts and does not claim full B&C/BIPSO-GR solver replay.
